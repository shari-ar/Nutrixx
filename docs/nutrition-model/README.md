[Foundation and calculation policy](foundation.md) defines nutrient identity,
units, food/recipe calculations, target semantics, missing data, uncertainty,
and rounding. Engine workflows live under [engine documentation](../engines/README.md);
verification policy lives under [quality](../quality/README.md).

Every material scientific claim MUST cite a primary authoritative source,
population/applicability, source version, effective date, and reviewer. Changes
are released as immutable scientific rule sets and pass regression evaluation.
