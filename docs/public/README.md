# Documentation static assets

Files in this directory are published at the root of the documentation site.

- `nutrixx-mark.png` is the site logo, favicon, and home-page mark.
- `nutrixx-wordmark.png` is available for documentation layouts that need the
  full brand name.

These files are exact copies of the canonical assets in
`apps/web/public/brand/`. Preserve their pixels, geometry, colors, and compression here;
replace them only by copying a newly approved canonical asset.
