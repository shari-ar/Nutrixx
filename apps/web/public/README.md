# Public Web assets

Static files served verbatim from the site root by Next.js.

## Rules

- Use stable, lowercase, descriptive filenames.
- Optimize images and other large assets before committing them.
- Never store secrets, source files, private health data, or downloadable dumps.
- Prefer imported assets when hashing and build-time optimization are required.
- Verify licensing and update `THIRD_PARTY_NOTICES.md` when attribution is needed.
