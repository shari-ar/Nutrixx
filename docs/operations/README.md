[Target operating model](target-operating-model.md) defines environments,
delivery, SLOs, observability, resilience, incident response, and launch gates.
Provider-specific runbooks are created only after the deployment platform is
selected.

Each runbook MUST state prerequisites, exact checks, expected output, safety
guards, rollback, escalation, owner, and last successful verification date.
Commands must be safe to copy, rerun, and audit.
