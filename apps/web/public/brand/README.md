## Usage

- Use the wordmark for navigation and prominent brand presentation.
- Use the square mark for browser icons and compact placements.
- Keep the wordmark on a light surface so its dark lettering remains legible.
- Decorative duplicates must use empty alternative text; meaningful logos use
  `Nutrixx`.
