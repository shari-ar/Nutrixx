# Web global styles

Global CSS entry points, Tailwind integration, design tokens, and unavoidable
document-wide styling.

## Rules

- Prefer utility classes and HeroUI tokens for component styling.
- Keep global selectors minimal and predictable.
- Define reusable color, spacing, typography, and motion values as tokens.
- Preserve keyboard focus, contrast, reduced-motion, and responsive behavior.
- Do not encode route-specific layout in global CSS.
